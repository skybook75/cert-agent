# 사내 인증서 교체 작업 절차 (예시)

이 문서는 PoC 검증용으로 작성한 사내 절차 예시입니다.

## 작업 공지
운영 서버 인증서를 교체할 때는 작업 3영업일 전까지 서비스 담당 부서와 고객센터에 작업 시간과 영향 범위를 공지합니다.
공지에는 작업 일시, 대상 도메인, 예상 중단 시간(통상 5분 이내), 원복 담당자 연락처를 적습니다.

## 작업 시간
운영 환경 교체는 평일 22시부터 다음 날 06시 사이에만 진행합니다. 금요일 야간과 공휴일 전날은 교체를 피합니다.

## 교체 후 확인
교체 직후 브라우저와 openssl s_client -connect 도메인:443 -servername 도메인 으로 새 인증서의 만료일과 체인을 확인합니다.
확인 결과는 인증서 관리 플랫폼의 배포 승인 화면에 첨부합니다.

## 원복 기준
교체 후 30분 안에 접속 오류율이 1%를 넘으면 직전 배포본으로 원복하고, 원복 사유를 플랫폼에 기록합니다.
